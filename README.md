# How to run

Install [Node.js](https://nodejs.org/) (version 22.12 or newer) and [Git](https://git-scm.com/downloads).

Open a terminal and run these commands one at a time:

```bash
git clone https://github.com/potatoes-00/final-project-forms.git
cd final-project-forms
npm ci
npm run build
npm start
```

Open **http://127.0.0.1:4173** in your browser.

To stop the app, press **Ctrl+C** in the terminal.

To run it again, open a terminal in the `final-project-forms` folder and run:

```bash
npm start
```
